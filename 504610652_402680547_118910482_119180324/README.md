# Lab01 — Métodos no supervisados

Entrega reproducible de ACP, HAC, K-Means, t-SNE y UMAP con el framework incluido.
Esta carpeta es independiente del repositorio principal; en otro equipo se
requieren Python y las dependencias indicadas en `requirements.txt`.

## Empezar

1. Abra PowerShell en la raíz de esta carpeta.
2. Siga [la guía de instalación, ejecución y verificación](COMO_EJECUTAR.md).
3. Consulte los resultados en `resultados` y el informe en
   `informe/plantilla_informe.tex`.

## Contenido

| Carpeta | Función |
|---|---|
| `data` | Datos confirmados para el laboratorio: 16 observaciones |
| `framework_ia` | Paquete local; incluye la clase `Cluster` |
| `scripts` | Ejecución de experimentos y comprobación de resultados |
| `resultados` | Parámetros, comparaciones, proyecciones y asignaciones |
| `informe` | Documento LaTeX y bibliografía; el PDF se obtiene al compilar |
